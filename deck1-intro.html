API key

What an API key is

✓ who you are ✓ how much used

Every time your program asks something, it sends its key.

The server checks who you are, and how much you've used.

Then it passes the message on to the model.

An API key is a password your program shows to an AI service.

API key

Get your key

1

Safety

Be careful what tools you give it

Runs any code the model writes

eval(code)

Runs any command on your computer

os.system(command)

Deletes files

delete_file(path)

Keep tools small and boring. The model can make mistakes.
